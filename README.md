Mushroom Edibility Classification using Machine Learning

Developed a Machine Learning classification project to predict whether a mushroom is edible or poisonous based on its characteristics.

Key tasks:
• Data Cleaning and Preprocessing
• Exploratory Data Analysis (EDA)
• Data Visualization
• Feature Engineering
• Model Training and Evaluation
• Comparing Machine Learning Classification Models
• Building an interactive Streamlit application

Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Streamlit.
